# Party Box CRM

CRM sencillo para Party Box (Nicaragua): conecta WhatsApp Business, detecta pedidos y cotizaciones en los mensajes y da seguimiento.

- Frontend: React + Vite (estático, GitHub Pages)
- Backend: Supabase (Postgres con RLS, Auth, Edge Functions `whatsapp-webhook` y `cuentas`)
